# agentic

Hooks and plugins for coding agents. Each folder is self-contained and has its own README.

## Hooks

| Folder | What it does |
| --- | --- |
| [hooks/review-gate](hooks/review-gate) | Blocks a pull request merge unless a review is recorded for its exact head commit. A GitHub Action sets a required status. A Claude Code hook stops an agent from running `gh pr merge` without the record. |
